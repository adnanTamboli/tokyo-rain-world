# 東京・雨 — Tokyo Rain

A cinematic, anime-style Three.js walk through Japan: neon **Tokyo** streets and a lakeside **Fuji village** (Kawaguchiko vibes) with Mount Fuji, a torii gate standing in the lake, a five-storey pagoda, thatched gassho houses and stone lanterns.

**Live:** https://adnantamboli.github.io/tokyo-rain-world/

- **4 seasons:** 🌸 spring sakura (falling petals) · ☔ rainy season (rain, puddle reflections, clear umbrella) · 🍁 autumn momiji (falling maple leaves) · ❄️ winter (snowfall, snow on roofs and ground)
- **Day / night:** glowing windows and lanterns, stars and moon, thunderstorms on rainy nights
- **Anime look:** toon shading, ink outlines, lens flare, bloom, letterbox bars, title cards, procedural koto music and ambience

## Controls
- **WASD / Arrows**: walk · **Shift**: run · **Click + move mouse**: look · **Scroll**: zoom
- **1–4**: season · **N**: day / night · **V**: Tokyo ⇄ Fuji village · **C**: cinema bars
- **Touch:** left thumb moves, right thumb looks · **Gamepad:** Y day/night, X/RB/LB season, B travel

Single `index.html` (Three.js r160 + three-vrm via CDN import map), no build step.
