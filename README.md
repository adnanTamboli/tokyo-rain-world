# 東京・雨 — Tokyo Rain

A cinematic Three.js walk through a rainy Tokyo street — anime daytime by default, neon night on toggle.

**Live:** https://adnantamboli.github.io/tokyo-rain-world/

## Controls
- **WASD / Arrows** — walk · **Shift** — run
- **Click + move mouse** — look (Esc frees cursor) · **Q / E** — turn view · **Scroll** — zoom
- **N** / HUD button / gamepad **Y** — day / night
- Touch joystick and gamepad supported

Single self-contained `index.html` (Three.js r160 via CDN import map) — no build step.
